# 前端界面改进说明

## 主要改进

### 1. 左侧菜单栏布局
- ✅ 固定左侧导航栏,宽度 256px (可收起至 64px)
- ✅ 优雅的菜单项设计,带图标和悬停效果
- ✅ 活跃状态高亮显示
- ✅ 可折叠功能,点击底部按钮收起/展开
- ✅ 收起时显示图标和 tooltip

### 2. 右侧功能区
- ✅ 主内容区域自适应左侧菜单宽度
- ✅ 统一的页面布局和间距
- ✅ 移除了顶部导航栏,改为左侧菜单

### 3. 样式优化
- ✅ 现代化的渐变背景 (slate-50 → blue-50/30 → slate-100)
- ✅ 卡片阴影和悬停效果
- ✅ 自定义滚动条样式
- ✅ 平滑的过渡动画
- ✅ 统一的圆角和间距
- ✅ 优化的色彩搭配

### 4. 组件改进
- ✅ 卡片组件添加 backdrop-blur 效果
- ✅ 按钮和交互元素的悬停状态
- ✅ 统计卡片的视觉层次
- ✅ 表格和列表的可读性优化

## 技术实现

### 布局上下文管理
使用 React Context 管理侧边栏状态:
- `LayoutProvider` - 提供全局布局状态
- `useLayout` - Hook 访问布局状态
- 侧边栏收起/展开状态全局同步

### 响应式设计
- 主内容区域根据侧边栏状态自动调整 margin-left
- 平滑的过渡动画 (300ms)
- 移动端友好的触摸交互

### 样式系统
- Tailwind CSS 4.0 配置
- 自定义主题变量
- 暗色模式支持
- 自定义滚动条样式

## 页面更新

所有页面已更新为新布局:
- ✅ 仪表盘 (`/`)
- ✅ API Keys 管理 (`/api-keys`)
- ✅ 项目管理 (`/projects`)
- ✅ 日志查看 (`/logs`)

## 使用说明

1. 启动开发服务器:
```bash
cd web
npm run dev
```

2. 访问 http://localhost:3000

3. 点击左侧菜单底部的按钮可以收起/展开菜单
