# UI 改进说明

## 概述
使用 shadcn/ui 组件库对管理界面进行了全面的现代化改造，提升了用户体验和视觉效果。

## 主要改进

### 1. 设计系统升级
- ✅ 集成 shadcn/ui 组件库
- ✅ 使用 Tailwind CSS v4 主题系统
- ✅ 现代化的配色方案（蓝色主题）
- ✅ 渐变背景和卡片阴影效果
- ✅ 响应式设计，支持移动端

### 2. 组件库
创建了以下可复用的 UI 组件：
- `Card` - 卡片容器组件
- `Button` - 按钮组件（多种变体）
- `Badge` - 徽章标签组件
- `Input` - 输入框组件
- `Table` - 表格组件

### 3. 页面改进

#### 仪表盘 (/)
- 🎨 渐变背景设计
- 📊 实时系统状态卡片（带动画指示器）
- 📈 关键指标统计（今日请求、活跃 Keys、响应时间、错误率）
- 🎯 功能卡片网格（带图标和悬停效果）
- 🎭 现代化的图标系统（lucide-react）

#### 项目管理 (/projects)
- 📦 项目卡片网格布局
- 🏷️ 状态徽章显示
- 📅 创建时间展示
- 🎨 悬停动画效果
- 📊 项目统计概览

#### API Keys 管理 (/api-keys)
- 🔑 表格化展示 API Keys
- 👁️ Secret 显示/隐藏切换
- 📋 一键复制功能
- 📊 统计数据卡片
- 🎨 状态徽章（活跃/禁用）
- ✨ 创建表单优化

#### 日志查看 (/logs)
- 📝 现代化表格设计
- 🎨 HTTP 方法彩色徽章
- 🚦 状态码颜色编码
- ⏱️ 响应时间颜色指示（绿/黄/红）
- 🔍 筛选条件卡片
- 📊 日志统计概览

#### 导航栏
- 🎯 固定顶部导航
- 🌟 渐变 Logo 设计
- 🎨 活跃状态高亮
- 📱 移动端响应式菜单
- 💚 系统运行状态指示器

## 技术栈

- **Next.js 16.2.4** - React 框架
- **React 19.2.4** - UI 库
- **Tailwind CSS v4** - 样式框架
- **shadcn/ui** - 组件库
- **lucide-react** - 图标库
- **class-variance-authority** - 组件变体管理
- **clsx & tailwind-merge** - 样式合并工具

## 设计特点

### 配色方案
- 主色：蓝色 (#3b82f6)
- 背景：渐变灰色
- 成功：绿色 (#10b981)
- 警告：黄色
- 错误：红色 (#ef4444)

### 交互效果
- 卡片悬停上浮效果
- 按钮过渡动画
- 状态指示器脉冲动画
- 加载状态旋转动画

### 响应式设计
- 移动端优先
- 平板适配
- 桌面端优化

## 启动项目

```bash
cd web
npm install
npm run dev
```

访问 http://localhost:3000 查看效果
